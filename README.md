# Overview

This is ChunkyJump, a game that features my in real life cat named Caesar. Caesar is food obsessed, so the main purpose of this game is to help Caesar reach his food! Move around with WASD, and pass parkour stages to reach your destination while avoiding Bean and Mickey, Caesar's siblings.

I created this for the main purpose of practice, learning more about C++/C# and Unity's layout for future projects.

[Software Demo Video](https://www.youtube.com/watch?v=aphqOhkbjtQ)

# Development Environment

The tools used to create this game were Unity and Visual Studio Code, along with smaller programs such as Github Desktop to help get the project uploaded to a repo.

The main programming language used to create this game was C++/C# along with some Unity namespaces, such as Runtime CompilerServices.
